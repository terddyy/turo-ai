match: powerpoint, powerpnt
SKILL: Microsoft PowerPoint
Layout: ribbon tabs (File, Home, Insert, Draw, Design, Transitions, Animations, Slide Show, Record, Review, View).
Slide thumbnails on the left, the current slide in the middle, notes bar below it.
Recipes (tab > button > menu item):
- New slide: Home > New Slide. Layout of a slide: Home > Layout.
- Theme: Design > pick a theme. Design ideas: Design > Designer. Slide size: Design > Slide Size.
- Picture/video/table/chart: Insert > Pictures / Video / Table / Chart.
- Transition between slides: Transitions > pick one. Animate an object: select it, Animations > pick one;
  order and timing: Animations > Animation Pane.
- Speaker notes: View > Notes (or the Notes button at the bottom).
- Present: Slide Show > From Beginning (F5). Rehearse timing: Slide Show > Rehearse Timings.
- Export video: File > Export > Create a Video. Save as PDF: File > Export > Create PDF/XPS.
