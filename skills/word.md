SKILL: Microsoft Word
Layout: ribbon tabs across the top (File, Home, Insert, Draw, Design, Layout, References, Mailings, Review, View).
Recipes (tab > button > menu item):
- Page numbers: Insert > Page Number > pick a position. Header/footer: Insert > Header or Footer.
- Table: Insert > Table > drag to choose size. Picture: Insert > Pictures. Page break: Insert > Page Break.
- Bullets/numbering: Home > Bullets or Numbering. Headings: Home > Styles (Heading 1, Heading 2).
- Line spacing: Home > Line and Paragraph Spacing. Find and replace: Home > Replace.
- Margins: Layout > Margins. Landscape: Layout > Orientation > Landscape. Two columns: Layout > Columns.
- Table of contents (needs headings): References > Table of Contents.
- Track changes: Review > Track Changes. Comment: Review > New Comment. Word count: Review > Word Count.
- Spelling: Review > Editor (or Spelling & Grammar). Voice typing: Home > Dictate.
- Save as PDF: File > Export > Create PDF/XPS.
Shortcuts: Ctrl+B bold, Ctrl+Enter page break, Ctrl+H replace, Ctrl+Z undo.
