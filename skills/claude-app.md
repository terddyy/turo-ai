SKILL: Claude (claude.ai and the Claude desktop app). Labels move between versions: confirm in the screenshot.
Layout: sidebar on the left (New chat, Chats, Projects, Artifacts; recent chats below). Your name or initials at
the bottom-left opens the menu with Settings. Message box at the bottom: "+" on its left (add files, connectors,
tools), model name on its right, send arrow at the far right.
Recipes:
- Use a Skill: Skills are turned on in Settings > Capabilities > Skills (toggle the ones you want; "Upload skill"
  adds your own .zip). Skills need "Code execution and file creation" on (same Capabilities page). Then just ask
  in a chat; Claude uses a matching skill by itself, or say "use the <name> skill".
- New chat: "New chat" at the top of the sidebar. Switch model: the model name in the message box.
- Attach a file or image: "+" in the message box > Add files (or drag the file in).
- Connect Google Drive, Gmail, etc.: Settings > Connectors (or "+" > connectors).
- Research or web search: the tools in the "+" / search-and-tools menu of the message box.
- Projects (saved instructions + files for a topic): sidebar > Projects > New project.
- Writing style: "+" or the tools menu > Use style.
- Memory, appearance, profile: Settings (bottom-left name > Settings).
