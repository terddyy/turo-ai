SKILL: Web browser (Chrome / Edge)
Layout: tabs along the very top, "+" for a new tab. Address bar below the tabs. Main menu is the three dots at the
top right ("⋮" in Chrome, "..." in Edge). Extensions: the puzzle-piece icon next to the address bar.
Recipes:
- New tab: "+" (Ctrl+T). Reopen a closed tab: Ctrl+Shift+T.
- Bookmark this page: the star in the address bar (Ctrl+D).
- Downloads: menu > Downloads (Ctrl+J). History: menu > History (Ctrl+H).
- Private window: menu > New Incognito window (Chrome) / New InPrivate window (Edge) (Ctrl+Shift+N).
- Zoom: menu > Zoom "+" / "-" (Ctrl + / Ctrl -).
- Save page as PDF: menu > Print (Ctrl+P) > Destination: Save as PDF.
- Find on page: Ctrl+F. Translate: the translate icon in the address bar.
- Clear browsing data: menu > Settings > Privacy > Delete/Clear browsing data (Ctrl+Shift+Delete).
- Saved passwords: menu > Passwords and autofill / Passwords.
