SKILL: Windows 11 File Explorer
Layout: command bar along the top (New, Cut, Copy, Paste, Rename, Share, Delete, Sort, View, "..." See more).
Navigation pane on the left (Home, Gallery, This PC, Downloads...). Address bar and search box above the files.
Recipes:
- New folder: New > Folder (or Ctrl+Shift+N), then type a name and press Enter.
- Rename: select the file, then the Rename icon in the command bar (or F2).
- Show file extensions: View > Show > File name extensions. Hidden files: View > Show > Hidden items.
- Bigger icons or details: View > Large icons / Details. Sort by date: Sort > Date modified.
- Zip: select files, right-click > Compress to ZIP file. Unzip: open the .zip, then Extract all in the command bar.
- Copy a file's path: select it, right-click > Copy as path.
- Find a file: click the search box (top right) and type.
- Properties / size: select it, "..." See more > Properties.
- New tab: the "+" next to the folder tab (Ctrl+T).
Delete is permanent from the Recycle Bin: always let the user click Delete themselves.
