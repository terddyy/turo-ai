SKILL: Microsoft Excel
Layout: ribbon tabs across the top (File, Home, Insert, Page Layout, Formulas, Data, Review, View). Each tab shows a
row of buttons below it. Cells are the grid; the formula bar is above the grid; sheet tabs are at the bottom.
Recipes (tab > button > menu item):
- Freeze top row: View > Freeze Panes > Freeze Top Row. First column: View > Freeze Panes > Freeze First Column.
- Sort: Data > Sort A to Z (or Home > Sort & Filter). Filter: Data > Filter (arrows appear in the header row).
- Remove duplicates: Data > Remove Duplicates. Split text: Data > Text to Columns. Dropdown list: Data > Data Validation.
- Chart: select the data, then Insert > Recommended Charts. PivotTable: Insert > PivotTable.
- Table look: Home > Format as Table. Highlight rules: Home > Conditional Formatting.
- Wrap text: Home > Wrap Text. Merge: Home > Merge & Center. Currency/percent: Home > Number Format dropdown.
- Insert row/column: Home > Insert > Insert Sheet Rows / Columns. Sum: Home > AutoSum.
- Show formulas: Formulas > Show Formulas. Hide gridlines: View > uncheck Gridlines.
- Print area: Page Layout > Print Area > Set Print Area. Landscape: Page Layout > Orientation > Landscape.
- Save as PDF: File > Export > Create PDF/XPS.
Shortcuts worth teaching: Ctrl+Z undo, Ctrl+Shift+L filter, Alt+= AutoSum, Ctrl+Arrow jump to data edge.
